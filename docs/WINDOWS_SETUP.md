# Complete Windows 10/11 Setup

## 1. Install prerequisites

Install:

1. **64-bit Python 3.11 or 3.12**. Enable `Add Python to PATH`.
2. **Git for Windows** if using Git.
3. **Microsoft Visual C++ Build Tools** only if pip reports a compiler error.
4. **Npcap** only for live packet capture. Enable WinPcap API compatibility when appropriate.
5. **Wireshark/TShark or Zeek through WSL/Docker** only for optional richer PCAP extraction.
6. **Docker Desktop** only if using the Docker deployment.

Verify in PowerShell:

```powershell
py --version
git --version
```

## 2. Extract the project

Extract the ZIP to a short path, for example:

```text
C:\VCODA_Advanced_Full_Project
```

Open PowerShell as a normal user and run:

```powershell
cd C:\VCODA_Advanced_Full_Project
```

## 3. Create the environment

Full CPU installation:

```powershell
powershell -ExecutionPolicy Bypass -File .\setup_windows.ps1 -Profile full
```

Training-only installation:

```powershell
powershell -ExecutionPolicy Bypass -File .\setup_windows.ps1 -Profile training
```

Activate:

```powershell
.\.venv\Scripts\Activate.ps1
```

Command Prompt alternative:

```bat
.venv\Scripts\activate.bat
```

If PowerShell blocks activation:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
```

## 4. GPU installation

Run `nvidia-smi`. Then use the exact PyTorch command generated by the official PyTorch selector for your driver/CUDA combination. Example structure:

```powershell
.\.venv\Scripts\python.exe -m pip uninstall -y torch torchvision torchaudio
.\.venv\Scripts\python.exe -m pip install torch torchvision torchaudio --index-url <official-CUDA-index-url>
```

Verify:

```powershell
python -c "import torch; print(torch.__version__); print(torch.cuda.is_available()); print(torch.cuda.get_device_name(0) if torch.cuda.is_available() else 'CPU')"
```

V-CODA falls back to CPU automatically.

## 5. Create `.env`

Setup copies `.env.example` to `.env`. Edit `.env` only when using optional services. Do not commit or share it.

## 6. Place the dataset

Extract all NF-UQ-NIDS-v2 CSV/CSV.GZ/Parquet files into:

```text
C:\VCODA_Advanced_Full_Project\data\raw\nf_uq_nids_v2\
```

The directory may contain one large CSV or multiple dataset files. Do not place only a ZIP/RAR/7z archive there.

## 7. Verify installation

```powershell
powershell -ExecutionPolicy Bypass -File .\windows\verify_installation.ps1
```

Expected checks include compilation, pytest, system report, and audit verification.

## 8. Inspect and prepare real data

```powershell
vcoda inspect-data --data-dir ".\data\raw\nf_uq_nids_v2"
vcoda prepare-data
```

Review:

```text
artifacts\reports\dataset_schema.json
artifacts\reports\leakage_report.json
data\processed\manifest.json
```

## 9. Train

```powershell
vcoda train supervised --task binary
vcoda train supervised --task multiclass
vcoda train anomaly
vcoda train deep --architecture mlp --task binary
vcoda train deep --architecture autoencoder --task binary
vcoda optimise-ensemble
vcoda evaluate
```

Automated workflow:

```powershell
powershell -ExecutionPolicy Bypass -File .\windows\train_all.ps1
```

Use `-SkipOptuna` for a faster first run.

## 10. Run services

API:

```powershell
vcoda serve-api
```

Dashboard in another terminal:

```powershell
.\.venv\Scripts\Activate.ps1
vcoda dashboard
```

Self-healing watchdog in another terminal:

```powershell
.\.venv\Scripts\Activate.ps1
vcoda heal --watch
```

Stop any service with `Ctrl+C`.

## 11. Windows Firewall mode

Leave disabled for normal testing. To enable in a lab:

1. Edit `configs\response_policy.yaml`.
2. Set `mode: human_approved` or `mode: windows_firewall`.
3. Set `windows_firewall.enabled: true`.
4. Start the relevant process as Administrator.
5. Keep confirmation required and use short block durations.
6. Test rollback before any lecturer demonstration.
