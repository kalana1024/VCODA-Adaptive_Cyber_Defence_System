01 Project එක මොකක්ද?

V-CODA kiyanne, network eka pass karana traffic (flows) balala eeka benign da (haniyak nathi) nattam attack da (malicious) kiyala decide karana, full-stack cybersecurity AI project ekak. Simple signature-based antivirus ekak wage nemei — meeka flow-level statistics (bytes, packets, duration, ports, TCP flags wagē features) balala, machine learning saha deep learning ekathu karala pattern eka analyze karanawa.

Core idea eka methanin: model ekak witharak use karanawa nemei — tree-based models (XGBoost, LightGBM, CatBoost...), deep learning architectures (MLP, CNN, LSTM, Transformer, Autoencoder), saha unsupervised anomaly detectors okkoma ekatu karala, ensemble ekak hadala eeka use karanawa. Eyin ekක් fail unath, wenath eka cover karanawa — mekata kiyanne defense in depth.

🎯

Goal eka: Real network traffic ekk balala — flow ekak "attack" da "benign" da kiyala confidence ekakin, explanation ekakin (ai monawada hitiye kiyala), saha risk score ekakin predict karanawa.

02 Architecture Overview

End-to-end pipeline eka mehema yanawa — dataset ingestion idan, live monitoring ekata wisiddi:

Raw NetFlow data → Prepare / clean / split → Preprocessing → Model training → Ensemble fusion → Engine (predict) → API / Dashboard

Codebase eka src/vcoda/ yatate module vidihata organize karala tියෙනවා — data, models, ensemble, anomaly, explainability, mitre, threat_intel, response, drift, audit, capture, api wage. Ehema hindā, module ekak change karama wenath ewata harm wenne nathuwa, "responsibility" eka clear widihata separate wela tියෙනවා.

Ehema components tika mokakda kalේ?

  • Explainability engine — SHAP values use karala, prediction ekak eliyata mokada thibbe kiyala explain karanawa (analyst kenekta review karanna puluwan widihata).
  • MITRE ATT&CK reasoner — detected attack category eka, known attack techniques ekata map karanawa.
  • Audit chain — blockchain-style hash chain ekak — sæma prediction ekakma tamper-proof widihata log karanawa.
  • Drift monitor — traffic pattern eka time ekkat wenas wenawada kiyala watch karanawa (concept drift).
  • Self-healing manager — model ekak corrupt unot / load wenne nattam, automatically fallback / recover karanna try karanawa.

03 Dataset saha Split Design

Use karala tියෙන්නේ NF-UQ-NIDS-v2 dataset eka — meeka NetFlow format ekata convert karapu, wenwena NIDS datasets (ToN-IoT, BoT-IoT, UNSW-NB15, CSE-CIC-IDS2018) combine karapu ekak. Interesting deshan ekk methana thiyenawa —

⚠️

Train / Validation / Test tunama wenwena network eken ganne. Train eka ToN-IoT + BoT-IoT walin, validation eka UNSW-NB15 walin, test eka CSE-CIC-IDS2018 walin. Meeka deliberate design decision ekak — cross-dataset generalization test karanna, i.e. ‟aluth network ekakata dala test karama model eka hodata work karanawada" kiyala check karanna.

Meeka realistic ekak, ithin challenging ekakuත් — model ekak train dataset ekata witharak "overfit" unoth, hariyata wenath network ekaka work karanne නෑ. Ithin methana score tika (accuracy wage) low unath, eeka bug ekak nemei — eeka real generalization difficulty ekak.

04 Train Karapu Models — Full List

Supervised (tree-based) — binary saha multiclass

XGBoost, LightGBM, CatBoost, Random Forest, Extra Trees — okkoma binary (attack/benign) saha multiclass (attack category — DDoS, DoS, Backdoor, Reconnaissance...) task dekatama train karala.

Deep learning — 5 architectures + 1 new

  • MLP — basic feed-forward network, BatchNorm + Dropout ekka.
  • CNN1D — 32-event sequence window ekaka temporal patterns balanawa.
  • CNN-LSTM — convolution + LSTM combine karapu sequence model ekak.
  • Transformer — self-attention use karana sequence model ekak.
  • Autoencoder — benign traffic witharak learn karala, reconstruction error ekan anomaly detect karanawa.
  • Multitask (aluth ekak) — shared encoder ekak, binary saha multiclass heads dekama ekathu — mekama best deep model eka unā (below results balanna).

Anomaly detection (unsupervised)

Isolation Forest, Local Outlier Factor, One-Class SVM — benign traffic witharak use karala train karala, "normal" nathi ewa flag karanawa. Online/streaming anomaly detector ekakuත් (River library, Half-Space Trees) live traffic ekata thiyenawa.

Ensemble — okkoma ekatu karana eka

Meke stacking ensemble ekak — deep binary models 6ම (autoencoder, cnn1d, cnn_lstm, mlp, multitask, transformer) ekathu karala, Logistic Regression meta-model ekak use karala final decision eka gannawa. Ithin single model ekaka weakness eka, wenath models walin cover wenawa.

05 Advanced Techniques — Meki Power-Up Round Eke Add Kale

Ape original problem eka thibbe — deep models tika real network ekaka test karama, hariyata perform karanne nathuwa "always benign" wage collapse wenawa. Eeka fix karanna, mē techniques tika add kala:

1. CORAL Domain Adaptation

Train data eke feature distribution eka, validation+test (unlabeled) data eke distribution ekata align karanawa — covariance matrix align karala. Labels use karanne nෑ, features witharak.

2. AdaBN (Adaptive BatchNorm)

Training iwara unාට passe, BatchNorm layers eke statistics tika, target-domain unlabeled data walin recompute karanawa — model eka deployment environment ekata "adjust" wenawa.

3. MC-Dropout Uncertainty

Prediction ekak dunama, Dropout layers active kara-genama 20 vaara forward pass karala, mean saha std ekak ganna — "confidence" ekak witharak nemei, "uncertainty" ekakuත් denawa.

4. Split-Conformal Calibration

Ensemble eke, validation data eken kotasak "calibration" ekata venuven wetuwa, statistically-guaranteed confidence threshold ekak ganawa — prediction ekak "confident" da nattam "review karanna oni" da kiyala flag karanawa.

5. Optuna Hyperparameter Search

Deep models walatath, tree models wage automatic hyperparameter tuning (learning rate, weight decay wage) add kala.

07 Hoyagath Bugs — Real Investigation Story

Bug 1: 1e30 Sentinel Value

Deep models okkoma "always predict benign" wenna hේthuwa hoyaddi therune — raw dataset eke src_to_dst_second_bytes column eke, "not applicable" kiyanna 1e30 wage astronomically loku number ekak use karala tibuna. Eeka missing value ekak widihata treat karanna wela, real number ekak widihata scale una gaman, variance eka 1e55 wage vibath una — BatchNorm layers okkoma poison una.

Fix eka: sentinel values NaN karala, existing median-imputation policy ekatama pass kala. Heavy-tailed features walata signed-log1p compression ekakuත් add kala.

Bug 2: Scapy Dissector Registration

PCAP file analysis eka, ithin "live monitoring" core feature ekama, kisidina hariyata work karala nathi bug ekak hoyagatta — scapy library eke PcapReader/rdpcap function, Ethernet/IP/TCP layers "register" karaganna kalin, packet dissect karanawa. Ithin real capture file ekak dunath, packets okkoma unparseable "Raw" bytes widihata silently degrade wela, flow ekakwath extract wenne nathuwa hitiya.

Fix eka: layer modules (scapy.layers.l2, scapy.layers.inet) rdpcap call karanna kalin explicitly import karala. Synthetic PCAP file ekak hadala verify kala — 40/40 flows dan hariyata extract wenawa.

08 Live Monitoring saha PCAP Analysis

Dan V-CODA ekata network traffic dෙන් vidiha dekakin dennawa —

  • vcoda analyse-pcap --input capture.pcap — existing .pcap file ekak analyze karala report ekak generate karanawa.
  • vcoda monitor-live --interface <name> — Npcap use karala, real-time widihata traffic capture karala, flow ekak complete unama ude predict karanawa.

Sequence-based deep models (cnn1d, cnn_lstm, transformer) ekata, source IP ekaka 32-event window ekak oni — ithin aluth source ekak dunama, poddak witharak "supervised model" ekaka fallback wela, 32 events waradi passe full ensemble ekata switch wenawa. Meeka dashboard ekaka "Ensemble usage" chart ekaka pennanawa.

09 API saha Dashboard

FastAPI Backend (vcoda serve-api)

  • /predict, /predict/batch — single/batch flow prediction.
  • /pcap/analyse — PCAP file upload karala analyze karanna.
  • /alerts, /incidents, /drift/status, /audit/verify, /models — monitoring/ops endpoints.
  • /metrics — Prometheus-format metrics (requests, predictions, latency).

Security features — VCODA_API_KEY set karama API key authentication enable wenawa, VCODA_RATE_LIMIT_PER_MINUTE set karama rate limiting enable wenawa. Set karanne nathnam (default), dev-friendly widihata open widihata run wenawa.

Streamlit Dashboard (vcoda dashboard)

Pages — Overview, Alerts, MITRE & Threat Graph, Model Comparison (full registry leaderboard eka), Drift & Self-Healing, Audit, PCAP & Live Monitoring, Settings.

11 Limitations — Ath Dath Ne Ethiya Ekak

  • Multiclass (attack category) detection eka innamath weak — 12-class problem ekaka severe cross-dataset shift ekaka best score eka 0.125 vithara (multitask model eke).
  • cnn_lstm eke ROC-AUC eka random ekatath adui — raw probability ranking eka reliable nathi unath, ensemble eka eeka absorb karanawa.
  • Model registry eke deep_binary slot eka, "best" model ekak nemei "last trained" model ekak hold karanawa — cosmetic issue ekak.
  • Live monitoring ekata Npcap saha (samahara environments walata) admin privileges oni wenna puluwan.

12 Ihala Ideas / Next Steps

  • Graph Neural Network ekak add karala, multi-host lateral-movement attacks detect karanna.
  • Deep models walata adversarial robustness testing (evasion attacks eka kohomada handle karanawada balanna).
  • Active-learning queue ekak — high-disagreement predictions tika, analyst review ekakata route karala, future retraining ekata use karanna.
  • Multiclass problem eka gina attention ekak denna — cross-dataset generalization ekata specific techniques.
  • Grafana dashboard ekak, /metrics endpoint eka use karala.
