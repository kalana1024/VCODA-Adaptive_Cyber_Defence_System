# Attribution and third-party status

V-CODA was designed from the supplied requirements. The repository `https://github.com/ifyouknowyou/A-hybrid-CTI-Framework` was reviewed as a conceptual reference for CTI text cleaning, IOC extraction, MITRE keyword mapping, and graph construction. Its visible repository did not provide a clear licence at packaging time, so **its source code is not copied or redistributed in this project**. V-CODA contains independently written local IOC, STIX, ATT&CK, and NetworkX components. Obtain written permission before incorporating source from that repository.

MITRE ATT&CK names and identifiers are configuration data and should be refreshed from MITRE's official STIX distribution when Internet synchronisation is configured. NF-UQ-NIDS-v2 is not included; obtain it from the University of Queensland and follow its citation and use terms.
